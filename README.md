# Network Automation

## Project Overview
This project is a collaborative network automation project designed to demonstrate a containerized network environment with a router, backend, and frontend components.

The project uses Docker Compose to manage the services and their network connections.

## Technologies Used
- HTML
- Docker Compose
- FRRouting (FRR)
- Nginx

## Project Structure
- backend/ - Backend component
- frontend/ - Frontend component
- frr/ - Router configuration
- docker-compose.yml - Service orchestration
